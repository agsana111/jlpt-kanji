# JLPT 한자 앱 설계 (v2)

> 기존 Python 데스크톱 앱은 `_legacy/`로 옮김. 이 문서가 새 앱의 기준이다.

## 1. 목표와 대상

- 대상: 한자 제로 베이스, 히라가나는 읽을 수 있음. 문법·청해는 다루지 않음. **한자만**.
- 시험: JLPT N3, 2027년 7월 첫째 일요일(7월 4일 예상).
- 신규 학습 완료 목표: **2027년 5월 말**. 6월~시험까지는 복습 전용.
- 플랫폼: 안드로이드 폰 위주. PWA(홈 화면 설치, 오프라인 동작). GitHub Pages로 배포.

## 2. 덱 구조

- **N5 / N4 / N3 덱 3개, 완전히 독립.** 덱마다 진도, 복습 스케줄, 목표일, 리포트가 따로 있다.
- 덱은 **미시작** 상태로 시작한다. 그 덱에서 **첫 테스트를 보는 순간** 스케줄이 돌기 시작하고 시작일이 기록된다.
- 단어 배정 규칙: **단어 안에서 가장 높은 레벨 한자 기준**으로 덱을 정한다. 카드 하나는 딱 한 덱에만 속한다.
- 덱 졸업: 모든 카드가 마스터면 졸업을 제안, 또는 수동으로 졸업. 졸업한 덱은 알고리즘이 멈추고 사전·자유 테스트만 남는다. 기록은 보존.

| 덱 | 한자 수 (추정) | 카드 수 (추정) | 완료 목표 |
|---|---|---|---|
| N5 | 약 100 | 약 200 | 12월 초 |
| N4 | 약 170~180 | 약 350 | 1월 말 |
| N3 | 약 370 | 약 750 | 5월 말 |

## 3. 카드

- 학습 단위는 **단어**. 한자마다 대표 단어 1~3개(빈도 높은 것, 읽기가 다른 것 우선).
- 앞면: 한자 단어만.
- 뒷면: 읽기(히라가나), 한국어 뜻, 한자 분해(한자별 음·훈, 부수), 실제 예문(후리가나 + 번역), 발음 듣기(기기 내장 TTS).
- 음독도 전부 히라가나로 표기.

## 4. 평가와 상태

- 자기평가 3버튼: **모름 / 애매 / 앎**.
  - 앎 = 읽기와 뜻이 바로 나옴. **읽기가 한 글자라도 다르면(장음·탁음·촉음) 애매.**
- 복습 간격: **FSRS** (ts-fsrs). 장기 스케줄은 그날 **첫 평가**로만 결정.
- 카드 상태 (자동):
  - 안 건드림: 한 번도 안 봄
  - 익히는 중: 처음 봤거나 최근에 틀림
  - 긴가민가: 애매를 눌렀거나 정답/오답 반복
  - 마스터: 21일 이상 간격에서 앎 2회 연속
  - 안 외워짐: 누적 오답 6회 이상 (자동) **또는 사용자가 직접 지정 (수동)**
- 수동 지정한 안 외워짐은 사용자가 해제하기 전까지 유지. 자동은 연속 정답 시 해제.
- 한자 상태는 그 한자가 들어간 단어 카드들의 결과로 자동 계산.

## 5. 하루 흐름

① 미리보기(신규, 평가 없음) → ② 테스트 → ③ 오답 반복(앎이 될 때까지, 섞어서) → ④ 마무리 테스트(오늘 본 전체) → ⑤ 오늘 리포트

- ③ 반복은 장기 스케줄에 영향 없음. ④에서 또 틀리면 다음 날로 당김.
- 단계마다 "여기서 끝내기". 진행 상황은 저장.
- 신규는 **10장 묶음** 단위. 묶음마다 ①~③, 마지막에 ④⑤.
- 5분 모드: 급한 복습만 10~20장, ②만.

## 6. 불규칙한 일정 대응

- 목표는 **주 단위 + 단계별 목표일** 기준. 스트릭 없음.
- 하루 복습 상한(기본 100, 전 덱 합계). 넘치면 잊었을 확률 높은 것 + 우선 덱부터.
- 밀린 복습이 많으면 신규 자동 정지.
- 신규 추가 전 미래 부담 예측 표시.
- 쉬는 기간 예고: 쉬기 전 곧 잊을 카드 미리 복습, 복귀 시 최근 배운 카드 우선.
- 진도 저금: 계획보다 앞선 만큼 표시.

## 7. 공통 기능

- 사전/검색: 한자, 읽기, 한국어 뜻, 영어 뜻. 미시작 덱 카드도 검색 가능.
- 자유 테스트: 범위 직접 선택. **스케줄에 영향 없음.** 틀린 것을 집중공략에 넣는 버튼만 제공.
- 집중공략: 자동/수동 구분, 부수 분해, 비슷한 한자 비교, 연상 메모.
- 백업: 파일 내보내기/불러오기, 주 1회 백업 알림.

## 8. 데이터

| 용도 | 소스 |
|---|---|
| 한자 레벨(N5~N3) | Jonathan Waller JLPT 목록 (kanji-data 경유) |
| 단어·읽기·영어 뜻·빈도 | JMdict |
| 한자 정보·부수 | KANJIDIC2, KRADFILE |
| 한자별 후리가나 정렬 | JmdictFurigana |
| 한국 한자음 | Unihan (kHangul) |
| 예문 | Tatoeba |

- 한국어 뜻·훈은 영어 뜻을 기준으로 번역 후 덱 단위 재검토. 신고 기능은 두지 않는다.
- 자동 검사: 읽기-후리가나 일치, 덱 배정, 예문 한자 레벨.
- 카드 ID는 JMdict 고유 번호 기반으로 고정. 데이터가 바뀌어도 학습 기록 유지.

## 9. 개발 단계

1. **1차**: N5 덱, 카드, FSRS, 하루 흐름 ①~⑤, 백업, PWA
2. **2차**: 사전/검색, 자유 테스트, 집중공략 상세, 쉬는 기간 예고
3. **3차**: N4·N3 데이터, 진도 저금, 미래 부담 예측

## 10. 제외

쓰기·획순, 히라가나 전용 단어, 가타카나 학습, 신고 기능, 계정·서버 동기화.
